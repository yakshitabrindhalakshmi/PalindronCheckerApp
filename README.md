# PalindronCheckerApp
The Palindrome Checker App is a simple console-based Java application developed to demonstrate basic programming concepts. The application starts by displaying a welcome message along with the application name and version information.

This use case focuses on understanding the Java program entry point (main() method), using classes, and displaying output using System.out.println(). It establishes the initial structure of the application before implementing the palindrome checking logic in later stages.
